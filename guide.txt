========================================================
  دليل بناء صفحات سورة البقرة — Guide for Building Section Pages
========================================================

This file explains every feature added to section-01.html and section-02.html
so you can replicate the same structure for sections 03–21.

========================================================
1. FILE STRUCTURE
========================================================

Each section is a standalone HTML file:
  section-01.html  (ayahs 1–5)
  section-02.html  (ayahs 6–7)
  section-03.html  (ayahs 8–20)
  ...
  section-21.html

All sections share:
  style.css   — all CSS (themes, tajweed, panels, layout)
  script.js   — all JS (toggles, panels, shortcuts, bookmarks)
  index.html  — table of contents linking to all sections

========================================================

<!-- Ayah [N] -->
<div class="ayah" id="ayah-[N]">
    <div class="ayah-text">[QURAN_TEXT_WITH_TAJWEED_SPANS]</div>
    <div class="ayah-num-wrap">

    <div class="tafseer-block">

            <button class="tafseer-tab-btn active" data-tab="saadi-[N]">السعدي</button>

            <button class="tafseer-tab-btn" data-tab="baghawy-[N]">البغوي</button>
            <button class="tafseer-tab-btn" data-tab="qortoby-[N]">القرطبي</button>
            <button class="tafseer-tab-btn" data-tab="tabary-[N]">الطبري</button>
        </div>
        <!-- Al-Saadi (default active, no collapse) -->
        <div class="tafseer-tab-content active" id="saadi-[N]">
            <div class="tafseer-text">[SAADI_TEXT]</div>
        </div>
        <!-- Ibn Kathir (collapsed) -->
        <div class="tafseer-tab-content" id="katheer-[N]">
            <div class="tafseer-text collapsed-text" id="t-katheer-[N]">[KATHEER_TEXT]</div>
            <button class="tafseer-toggle" onclick="toggleTafseerText('t-katheer-[N]', this)">عرض المزيد</button>
        </div>
        <!-- Al-Baghawi (collapsed) -->
        <div class="tafseer-tab-content" id="baghawy-[N]">
            <div class="tafseer-text collapsed-text" id="t-baghawy-[N]">[BAGHAWY_TEXT]</div>
            <button class="tafseer-toggle" onclick="toggleTafseerText('t-baghawy-[N]', this)">عرض المزيد</button>
        </div>
        <!-- Al-Qurtubi (collapsed) -->
        <div class="tafseer-tab-content" id="qortoby-[N]">
            <div class="tafseer-text collapsed-text" id="t-qortoby-[N]">[QORTOBY_TEXT]</div>
            <button class="tafseer-toggle" onclick="toggleTafseerText('t-qortoby-[N]', this)">عرض المزيد</button>
        </div>
        <!-- Al-Tabari (collapsed) -->
        <div class="tafseer-tab-content" id="tabary-[N]">
            <div class="tafseer-text collapsed-text" id="t-tabary-[N]">[TABARY_TEXT]</div>
            <button class="tafseer-toggle" onclick="toggleTafseerText('t-tabary-[N]', this)">عرض المزيد</button>
        </div>
    </div>
</div>

IMPORTANT:
- [N] = ayah number (e.g. 6, 7, 8...)
- [N_AR] = Arabic-Indic numeral (e.g. ٦, ٧, ٨...)
- Al-Saadi tab is "active" by default and NOT collapsed
- Other 4 scholars are collapsed with "عرض المزيد" toggle button
- Tab IDs use the pattern: saadi-N, katheer-N, baghawy-N, qortoby-N, tabary-N
- Collapsed text IDs use: t-katheer-N, t-baghawy-N, t-qortoby-N, t-tabary-N

5. TAJWEED COLOR CODING — HOW TO MARK UP AYAHS
========================================================

The tajweed spans are INSIDE the <div class="ayah-text"> element.
Only specific letters get wrapped. Unaffected text stays unwrapped.

--- 7 RULES AND THEIR CSS CLASSES ---

Rule        | Arabic   | Class     | When to apply
------------+----------+-----------+----------------------------------------
Ghunnah     | غنة      | tj-ghn    | نّ or مّ (noon/meem with shaddah)
Ikhfa       | إخفاء    | tj-khf    | Noon sakinah/tanween before:
            |          |           | ت ث ج د ذ ز س ش ص ض ط ظ ف ق ك
Idgham      | إدغام    | tj-dgm    | Noon sakinah/tanween before: ي ر م ل و ن
Iqlab       | إقلاب    | tj-qlb    | Noon sakinah/tanween before: ب
Qalqalah    | قلقلة    | tj-qlq    | Letters ق ط ب ج د when sakin (sukoon)
Madd        | مد       | tj-mdd    | Dagger alif (ـٰ), madd lazim (لۤمۤ),
            |          |           | madd muttasil/munfasil (اۤ before hamza),
            |          |           | yaa/waw madd in key words
Silent      | صامت     | tj-slt    | Alif wasl (ٱ), lam shamsiyyah before
            |          |           | sun letters, silent waw (و۟), silent alif (ا۟)

--- HOW TO WRAP ---

Wrap ONLY the affected letters in a <span class="tj-XXX">...</span>.

Examples from the existing sections:

  GHUNNAH (نّ / مّ with shaddah):
    وَمِ<span class="tj-ghn">مَّ</span>ا           ← مّ in مِمَّا (ayah 3)
    إِ<span class="tj-ghn">نَّ</span>              ← نّ in إِنَّ (ayah 6)
    <span class="tj-ghn">مِّ</span>               ← مّ in مِّن (ayah 5, result of idgham)

  IKHFA (noon sakinah before ikhfa letter):
    یُ<span class="tj-khf">نف</span>ِقُونَ        ← نْ before ف (ayah 3)
    أُ<span class="tj-khf">نز</span>ِلَ            ← نْ before ز (ayah 4)
    مِ<span class="tj-khf">ن</span> قَبۡلِكَ        ← نْ before ق (ayah 4)
    ءَأَ<span class="tj-khf">نذَ</span>رۡتَهُمۡ     ← نْ before ذ (ayah 6)

  IDGHAM (tanween/noon sakinah merging into يرملون):
    هُ<span class="tj-dgm">دࣰى</span> لِّ          ← tanween before ل (ayah 2)
    هُ<span class="tj-dgm">دࣰى</span> مِّ          ← tanween before م (ayah 5)
    <span class="tj-dgm">ن</span> رَّ              ← noon sakinah before ر (ayah 5)

  IQLAB (tanween/noon sakinah before ب):
    Not present in ayahs 1–7. Example pattern:
    مِ<span class="tj-qlb">نۢ ب</span>َعۡدِ        ← نْ before ب → pronounced as م

  QALQALAH (ق ط ب ج د with sukoon):
    رَزَ<span class="tj-qlq">قۡ</span>نَـٰهُمۡ      ← قْ sakin (ayah 3)
    قَ<span class="tj-qlq">بۡ</span>لِكَ            ← بْ sakin (ayah 4)
    أَ<span class="tj-qlq">بۡ</span>صَـٰرِهِمۡ       ← بْ sakin (ayah 7)

  MADD (elongation):
    رَّحۡ<span class="tj-mdd">مَـٰ</span>نِ         ← dagger alif (ayah 1)
    رَّحِ<span class="tj-mdd">ی</span>مِ            ← yaa madd (ayah 1)
    ا<span class="tj-mdd">لۤ</span><span class="tj-mdd">مۤ</span>  ← madd lazim (ayah 1)
    بِمَ<span class="tj-mdd">اۤ</span> أُنزِلَ       ← madd munfasil (ayah 4)
    عَلَ<span class="tj-mdd">ىٰ</span>              ← alif maqsurah + superscript alif (ayah 7)
    سَوَ<span class="tj-mdd">اۤ</span>ءٌ            ← madd muttasil (ayah 6)

  SILENT (unpronounced letters):
    <span class="tj-slt">ٱ</span>للَّهِ            ← alif wasl (ayah 1)
    <span class="tj-slt">ٱل</span>رَّحۡمَـٰنِ       ← alif wasl + lam shamsiyyah (ayah 1)
    <span class="tj-slt">ٱل</span>صَّلَوٰةَ         ← lam shamsiyyah before ص (ayah 3)
    كَفَرُو<span class="tj-slt">ا۟</span>           ← silent alif (ayah 6)
    أُ<span class="tj-slt">و۟</span>لَـٰۤىِٕكَ       ← silent waw (ayah 5)

--- SUN LETTERS (lam shamsiyyah = mark ٱل as silent) ---
  ت ث د ذ ر ز س ش ص ض ط ظ ل ن
  If ال comes before one of these, the ل is silent.
  Example: ٱلصَّلَوٰةَ → <span class="tj-slt">ٱل</span>صَّلَوٰةَ

--- MOON LETTERS (lam qamariyyah = ل is pronounced, only mark ٱ) ---
  ا ب ج ح خ ع غ ف ق ك م و ه ي
  Example: ٱلۡكِتَـٰبُ → <span class="tj-slt">ٱ</span>لۡكِتَـٰبُ

--- TIPS ---
- When ikhfa spans a word boundary (مِن قَبۡلِكَ), wrap each part separately:
    مِ<span class="tj-khf">ن</span> قَبۡلِكَ
- When idgham results in ghunnah (tanween + م), mark BOTH:
    هُ<span class="tj-dgm">دࣰى</span> <span class="tj-ghn">مِّ</span>ن
- Spans do NOT break Arabic letter connections in modern browsers.
- When tajweed is OFF, all spans inherit parent color (invisible).

========================================================
7. MEMORIZE MODE (3 levels)
========================================================

Level 0: Off (normal view)
Level 1: القراءة — reading mode (subtle highlight, no hiding)
Level 2: الكلمة الأولى — shows only first word, rest blurred
         Click ayah to reveal/hide
Level 3: الاختبار — full test, everything hidden
         Click ayah to reveal/hide

The JS handles all this automatically via body classes:
  .memorize-level-1, .memorize-level-2, .memorize-level-3, .memorize-mode


========================================================
8. BOOKMARKS
========================================================

- Double-click any ayah to bookmark/unbookmark it
- Adds .bookmarked class to the ayah div
- Stored in localStorage as array: bq-bookmarks = [3, 5, 12]
- The bookmarks panel (العلامات) shows bookmarked ayahs on current page
- Each item shows ayah number + first 3 words
- Click × to remove, click item to scroll to ayah
- Bookmarks work across pages (stored globally)


========================================================
9. FLOW DIAGRAM
========================================================

Vertical diagram showing the thematic flow of ayahs in the section.
- Collapsible (state saved in localStorage: bq-flow-collapsed)
- Each node links to its ayah (click to scroll)
- Structure: flow-node → flow-arrow → flow-node → ...
- data-ayahs attribute: single number "6" or range "8-10"


========================================================
10. NAVIGATION BAR
========================================================

At the bottom of each section, two links:
- Previous section (right side, RTL)
- Next section (left side, RTL)

First section: use <span class="nav-btn disabled"></span> for prev
Last section: use <span class="nav-btn disabled"></span> for next


========================================================
11. THEMES (3 modes)
========================================================

Light (default): no body class
Dark:            body.dark-mode
Sepia:           body.sepia-mode

All CSS uses custom properties (--bg-primary, --text-ayah, etc.)
that change per theme. Tajweed colors also adapt per theme.
